    Dual-feed emission — YouTube Dual Stream (Encoder mode)
    
            
    Two Browser Sources in one scene do not create two YouTube feeds on their own: one OBS program output carries one feed. To emit both compositions, YouTube Studio Dual Stream is set to Encoder mode with two stream keys (horizontal + vertical, same broadcast, shared chat), and this machine encodes both feeds — for example with the free Aitum Vertical plugin (a second 1080×1920 canvas with its own streaming output) or a second portable OBS instance. Encoder mode cannot be added after the stream starts; verify both previews before going live. Auto mode (a YouTube-generated crop of the horizontal feed) remains the no-extra-encoder fallback. See docs/t4f-c2-delivery.md for the full startup and rehearsal checklist. Nothing here starts a broadcast.
    
            
    Canvas and source dimensions
    
            
    Landscape: OBS canvas 1920×1080 (output 1920×1080 or 1280×720) · Browser Source 1920 wide × 1080 high. Portrait: OBS canvas 1080×1920 (output 1080×1920 or 720×1280) · Browser Source 1080 wide × 1920 high. Always use the URL whose dimensions match the canvas.

    Source behavior and troubleshooting
    
            
    Fit the source to the canvas with the source Transform controls (for example Fit to screen). Refresh the Browser Source to reload the overlay after updates — it resubscribes and catches up; the stream session is untouched. The “shutdown source when not visible” option frees resources but reloads the overlay when reshown. If the overlay stutters, check the browser-source hardware acceleration option in the OBS advanced settings. If text looks small, the canvas and source dimensions likely mismatch — recheck the numbers above. Audio routing is not managed by Tidebound; configure audio in OBS and YouTube directly.
    
            
    Chat moderation boundary
    
            
    YouTube slow mode and subscriber-only chat are YouTube Studio settings — configure them there. Tidebound cannot change them: command cooldowns limit game actions, the event queue limits presentation volume, and the chat integration only reads messages and posts vote announcements. No extra moderation permissions were added.
